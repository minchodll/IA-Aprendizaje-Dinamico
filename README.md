# IA-Aprendizaje-Dinamico

Inteligencia Artificial para el aprendizaje dinámico en estudios de computación mediante generación y evaluación automática de contenido.

---

## Desarrollo del Proyecto (React)

Este proyecto fue creado con **Create React App**.

### Comandos Disponibles

En la carpeta del proyecto, puedes ejecutar:

* `npm start`: Inicia la aplicación en modo de desarrollo en [http://localhost:3000](http://localhost:3000).
* `npm run build`: Compila la aplicación para producción en la carpeta `build`.
